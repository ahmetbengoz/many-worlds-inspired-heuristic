# Release notes: v2.0.0

This release provides the reproducibility package for the MWI-H TSPLIB benchmark study.

Included materials:

- MWI-H implementation
- SA, GA, ACO, and ABC/BCO baseline implementations
- TSPLIB input files used in the manuscript
- Standard experiment scripts
- Per-run and summary result files
- Convergence and entropy curves
- Generated figures and tables
- Reproducibility runbook

After creating this GitHub release, Zenodo should generate a new archived version DOI through the GitHub-Zenodo integration. Use that DOI in the manuscript Data and Code Availability statement.
